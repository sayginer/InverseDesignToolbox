# results/

Empty on purpose. The scripts write here:

* `SIM_HarmonicMotion.m` saves your simulation parameters as `results/<ProblemName>.mat`. Run it first: every `CASE_*.m` case study loads that file.
* The case studies save their results (`.mat`) and the manufacturable shapes (`.stl`) here.

Everything in this folder can be deleted and recreated by running the scripts again.
